## 🎯 Core Idea

This paper addresses the critical question: **"How well does a YOLO model generalize when deployed in a visually different environment?"**

We propose using **Fréchet Inception Distance (FID)** to quantify domain shift between training and deployment distributions, combined with hardware profiling to assess real-world deployment feasibility.

### Key Contribution
An **automated domain shift detection pipeline** that:
1. Computes FID between train/test image distributions using InceptionV3 features
2. Profiles model complexity (GFLOPs, params, latency, VRAM)
3. Generates publication-ready LaTeX comparison tables

---

## 📐 Mathematical Framework

### Fréchet Inception Distance
```
FID = ||μ_1 - μ_2||² + Tr(Σ_1 + Σ_2 - 2√(Σ_1 · Σ_2))
```
Where:
- `μ_1, μ_2` = feature means of domain A and B
- `Σ_1, Σ_2` = feature covariances
- Lower FID = more similar distributions

### Model Complexity Metrics
```
GFLOPs = (MACs × 2) / 1e9
Latency = mean(CUDA event timing over 100 inference runs)
Peak_VRAM = max(nvmlDeviceGetMemoryInfo during inference)
```

## 🔬 Experimental Setup

- **Domains:** Day photos vs. Night photos, Clear vs. rainy, Indoor vs. Outdoor
- **Models:** YOLOv8n, YOLOv8s, YOLO26n
- **Feature Extractor:** InceptionV3 (pre-trained on ImageNet)
- **Hardware:** RTX 4090, measured with NVML and CUDA events
